# WiFi Monitor

Aplikasi Android sederhana untuk memantau koneksi Wi-Fi.

## Fitur
- SSID Wi-Fi
- Kekuatan sinyal dalam dBm
- Level sinyal
- IP address
- Gateway
- Link speed
- Frekuensi Wi-Fi
- Ping gateway

## Build
1. Buka folder `WifiMonitor` dengan Android Studio.
2. Tunggu Gradle selesai melakukan sync.
3. Hubungkan perangkat Android atau gunakan emulator.
4. Jalankan `app`.
5. Izinkan permission lokasi ketika diminta. Pada beberapa versi Android, permission lokasi diperlukan agar informasi SSID Wi-Fi dapat dibaca.

## Catatan
Versi awal ini hanya memonitor jaringan yang sedang digunakan. Fitur pemindaian perangkat LAN dapat ditambahkan pada versi berikutnya.
